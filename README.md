# KeeneticAutoSwitchDNS

Скрипт автоматического переключения профилей DNS / Контентной фильтрации на роутерах **Keenetic** при отказе локальных DNS-серверов (например, AdGuard Home / Pi-hole).

Разработан специально для запуска **непосредственно на самом интернет-центре Keenetic** (в среде Entware / OPKG).

---

## Логика работы
1. **Проверка фильтра:** Если контентный фильтр на роутере отключен — скрипт **ничего не делает**.
2. **Поиск профиля:** Ищет профиль с именем `AutoSwitchDNS` (регистронезависимо). Если профиль не существует — скрипт **ничего не делает**.
3. **Автоматическое извлечение серверов (включая DoH и DoT):**
   - **Обычный DNS:** Извлекает IP-адрес сервера (порт 53).
   - **DoT (DNS-over-TLS):** Автоматически достает адрес из поля `address` (порт 853).
   - **DoH (DNS-over-HTTPS):** Извлекает хост из URL вида `https://.../dns-query`.
   - **Резолв локальных доменов без DNS:** Если в DoH указано локальное имя (например, `https://adguard.home/...`), скрипт находит реальный IP устройства во внутренней базе подключенных клиентов роутера (`/rci/show/ip/hotspot` и `/rci/show/rc/ip/host`), не требуя работающего DNS!
4. **Проверка доступности:**
   - Выполняет быстрый ICMP-пинг (`ping -c 1 -W 1`).
   - При необходимости проверяет доступность целевого TCP-порта (443 для DoH, 853 для DoT).
5. **Переключение:**
   - Если **хотя бы один** сервер доступен $\rightarrow$ включает профиль `AutoSwitchDNS`.
   - Если **ни один** сервер не доступен $\rightarrow$ переключает на профиль `Системный` (`default`).
6. Если профиль уже установлен, роутер не выполняет повторную запись настроек и сохранение конфигурации.

---

## Режимы переключения сегментов
Параметр режима позволяет выбрать целевые сети:
- `home` — переключать только **Домашнюю сеть**.
- `guest` — переключать только **Гостевую сеть**.
- `both` — переключать **обе сети** (по умолчанию).

## Установка через OPKG (.ipk пакет) — Самый простой способ ⭐

В репозитории есть готовый скрипт сборки пакета `build-ipk.sh`. Пакет собирается с архитектурой `all` и подходит для **любых роутеров Keenetic** (MIPS, ARM, aarch64).

### 1. Сборка пакета (если нужно собрать заново):
```bash
sh build-ipk.sh
```

На выходе получается файл: `keenetic-autoswitch-dns_<version>_all.ipk`.

### 2. Установка на роутере:
Скопируйте пакет в `/tmp/` роутера и выполните установку:
```bash
opkg install /tmp/keenetic-autoswitch-dns_<version>_all.ipk
```

> **Что сделает OPKG автоматически:**
> 1. Автоматически установит зависимость `jq` из репозитория.
> 2. Разложит файлы `/opt/bin/autoswitch.sh` и `/opt/etc/init.d/S99autoswitch` с правильными правами доступа.
> 3. Автоматически запустит службу-демон.

### 3. Управление службой:
```bash
/opt/etc/init.d/S99autoswitch status   # Проверить статус
/opt/etc/init.d/S99autoswitch restart  # Перезапустить
/opt/etc/init.d/S99autoswitch stop     # Остановить
```

### 4. Удаление:
```bash
opkg remove keenetic-autoswitch-dns
```
*(Корректно остановит демон и начисто удалит все файлы скрипта)*

## Ручная установка (без пакета)

### 1. Подготовка
Подключитесь к Entware по SSH (обычно порт `222`):
```bash
ssh root@192.168.1.1 -p 222
```

### 2. Установка скрипта
1. Установите парсер JSON:
   ```bash
   opkg update && opkg install jq
   ```
2. Скопируйте `autoswitch.sh` в `/opt/bin/autoswitch.sh` и сделайте исполняемым:
   ```bash
   chmod +x /opt/bin/autoswitch.sh
   ```
3. Проверьте запуск вручную:
   ```bash
   # Проверить обе сети (Home + Guest):
   /opt/bin/autoswitch.sh both

   # Только домашнюю сеть:
   /opt/bin/autoswitch.sh home
   ```

## Автозапуск: Фоновая служба Entware (`/opt/etc/init.d/S99autoswitch`)

Служба-демон:
- **Не спамит в системный журнал роутера**.
- Быстро реагирует на сбой (проверка каждые 20–30 секунд).
- Потребляет **0% CPU** в режиме ожидания (`sleep`).
- Автоматически запускается при загрузке Keenetic.

### Установка службы вручную:
1. Скопируйте файл `S99autoswitch` в `/opt/etc/init.d/S99autoswitch` и сделайте исполняемым:
   ```bash
   chmod +x /opt/etc/init.d/S99autoswitch
   ```
2. Запустите службу:
   ```bash
   /opt/etc/init.d/S99autoswitch start
   ```
3. Управление службой:
   ```bash
   /opt/etc/init.d/S99autoswitch status   # Проверить статус
   /opt/etc/init.d/S99autoswitch restart  # Перезапустить
   /opt/etc/init.d/S99autoswitch stop     # Остановить
   ```
